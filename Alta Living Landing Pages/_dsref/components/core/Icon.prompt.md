Renders a Lucide glyph from CDN — use it anywhere the source used `lucide-react`.

```jsx
<Icon name="map-pin" size={12} />
<Icon name="arrow-right" size={16} color="var(--rust)" />
```

Alta uses only Lucide, at default stroke weight. Never emoji, never hand-drawn SVG. Common slugs in the product: `bed`, `door-open`, `map-pin`, `star`, `home`, `arrow-right`, `wifi`, `check`.
