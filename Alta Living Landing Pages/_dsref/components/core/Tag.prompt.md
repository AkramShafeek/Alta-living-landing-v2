Square metadata chip used on property cards, testimonials and photo overlays.

```jsx
<Tag icon="map-pin">Indiranagar, Bangalore</Tag>
<Tag tone="glass">2 BHK</Tag>
<Tag tone="wash" icon="map-pin">Assagao, North Goa</Tag>
```

Only `tone="glass"` is a pill — every other tone keeps hard 0px corners.
