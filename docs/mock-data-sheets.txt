HOW TO USE
  1. Create a tab named exactly as the block heading (e.g. "properties").
  2. Format the sheet as plain text first: Format > Number > Plain text. This keeps
     values like 12,000 / 560038 / 14/03/2021 / TRUE from being reinterpreted by Sheets.
  3. Select the block rows below - header row included - and copy.
  4. Click A1 in the tab and paste. Columns are TAB-separated, so Sheets splits them.
     If it all lands in column A: Data > Split text to columns > Separator: Tab.

NOTES
  - Empty cells are intentionally empty (optional fields).
  - Booleans are the literal strings TRUE / FALSE.
  - Pipe-separated lists (e.g. languages: English|Kannada|Hindi) stay in one cell.
  - Every row currently belongs to prop_001 / host_meera.

DO NOT PUBLISH THE hosts TAB
  It holds phone and whatsapp for a real person, and Publish to web is
  world-readable. The hosts table reads from the fixture on purpose and has
  no env switch. Keep the tab private, or leave it out of the spreadsheet.
